# PRESTIGE Media Guide

This guide defines the media slots for the Prestige project.

## File Naming Convention

All files must be saved in `src/assets/prestige/` with the exact names below.

### Projects

- `prestige-project-01.webp` (Recommended: 1800x1350)
- `prestige-project-02.webp` (Recommended: 1400x1867)
- `prestige-project-03.webp` (Recommended: 1400x1867)
- `prestige-project-04.webp` (Recommended: 1800x1125)

### Before & After

Pairs must have identical dimensions.

- `prestige-before-after-01-before.webp`
- `prestige-before-after-01-after.webp`
- `prestige-before-after-02-before.webp`
- `prestige-before-after-02-after.webp`
- `prestige-before-after-03-before.webp`
- `prestige-before-after-03-after.webp`

### Reserved

- `prestige-about-01.webp`
- `prestige-service-interior-01.webp`
- `prestige-service-exterior-01.webp`
- `prestige-service-construction-01.webp`
- `prestige-service-maintenance-01.webp`
- `prestige-process-01.webp`
- `prestige-why-01.webp`
- `prestige-service-area-01.webp`
- `prestige-contact-01.webp`
- `prestige-og-cover.webp`

## Technical Requirements

- Format: .webp (preferred)
- Quality: 78-85
- Max Size: < 500KB per file
- Do not rename files; the manifest depends on exact filenames.
